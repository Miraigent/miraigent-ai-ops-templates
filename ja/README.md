このリポジトリでは、AI運用の無料テンプレートと、AI運用を補助するMCPスターターを公開しています。

- [無料テンプレート](../free/README.md)。
- [MCPスターターの使い方](../mcp/ai-ops-template-server/README.md)。

AI導入前の確認、FAQ候補、CRMメモ、AIへ渡す情報の整理、人による確認フローなどを扱います。

## 提供範囲

このリポジトリでは公開AI運用テンプレートと、テンプレートの検索、人による確認用チェックリスト、導入計画を支援するMCPスターターを提供しています。MCPサーバーはプロンプト、ツールの実行結果、運用メモを保存・取得しません。

個人情報、顧客情報、認証情報、非公開の業務情報を公開Issueへ書かないでください。ライセンスの適用範囲は[LICENSE-SCOPE.md](../LICENSE-SCOPE.md)で確認できます。
